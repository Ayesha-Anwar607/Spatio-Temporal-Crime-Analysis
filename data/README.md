## 💾 Dataset Setup
The Chicago Crimes dataset is too large to host directly on GitHub. To run this project locally or in Colab:
1. Download the dataset directly from Kaggle  . (https://www.kaggle.com/datasets/adelanseur/crimes-2001-to-present-chicago).
2. Place the downloaded `Crimes_-_2001_to_Present.csv` file inside a folder named `data/` in the project root directory.
